# 04 · 发布到微信小游戏

> 目标：把 Cocos 工程构建成微信小游戏包，在微信开发者工具里真机预览并上传审核。
> 前置：**企业主体**的微信小程序账号（游戏类目）、微信开发者工具、已备案的服务器域名（如需远程资源）。

---

## 0. 先确认资质（最容易卡住的一步）

微信小游戏属于「小程序 · 游戏」类目，国内正式上线通常需要：

| 资质 | 说明 |
| --- | --- |
| 小程序账号（企业） | 个人主体不能开通游戏类目，也无法申请版号 |
| 游戏版号（ISBN） | 含内购/虚拟支付必须；纯广告变现也建议办理，平台会按最新类目要求校验 |
| 小程序备案 | 2023 年起所有小程序需完成 ICP 备案 |
| 软著 | 游戏软件著作权，办理版号的前置材料 |
| 隐私保护指引 | 在公众平台配置，声明收集的信息 |

> 规则会变，提交前以微信公众平台「设置 → 基本设置 → 服务类目」的实际要求为准。
> 如果暂时没有版号，可以先把 **海外版 / H5 试玩版** 放出去，国内小游戏等资质齐了再上。

## 1. Cocos 构建微信小游戏

「项目 → 构建发布」新建 **微信小游戏** 任务：

| 选项 | 建议值 |
| --- | --- |
| 游戏包名 / AppID | 填公众平台的小游戏 AppID（`wx` 开头） |
| 设备方向 | **portrait** |
| 渲染后端 | WebGL 1.0（兼容性最好） |
| 资源服务器地址 | 留空先用本地包；包体大了再上 CDN |
| 首屏包体 | 默认 |

产物：`build/wechatgame/`，包含 `game.js`、`game.json`、`project.config.json`、`assets/` 等。

### 包体限制

- 主包 ≤ **4MB**，分包总计 ≤ **20MB**（以官方最新公告为准）。
- 本项目目前主包 < 1MB：代码 ~200KB、子集字体 43KB、图标/背景 ~150KB、音频 ~40KB。
- 后续加内容时的优先级：
  1. 图片压缩（TexturePacker 合图 + WebP）
  2. 音频降采样（22kHz 单声道 mp3）
  3. 大图/多语言放分包或 CDN

## 2. 微信开发者工具

1. 打开微信开发者工具 → 导入项目 → 选择 `build/wechatgame/`。
2. AppID 填小游戏 AppID（不是订阅号/服务号的）。
3. 首次会提示「未配置服务器域名」——本地包可以忽略；用 CDN 时要在公众平台配置
   `downloadFile` / `request` 合法域名（必须 HTTPS）。
4. 点「预览」扫码真机测试，重点看：
   - 首屏加载时间（目标 < 3 秒）
   - 点击箭头的手感与帧率（目标 60fps）
   - 音效在静音键 / 微信语音通话后是否恢复
   - 刘海屏安全区

### game.json 关键项

```json
{
  "deviceOrientation": "portrait",
  "showStatusBar": false,
  "networkTimeout": { "request": 10000, "downloadFile": 10000 },
  "subpackages": []
}
```

Cocos 构建会自动生成，一般不用手改；加分包时在这里登记。

## 3. 平台能力接入

### 3.1 分享

`assets/scripts/cocos/Platform.ts` 已经封装：

```ts
Platform.share('一箭清空：这关我卡了 10 分钟');
```

微信侧还需要在 `game.js` 里注册被动分享：

```js
wx.showShareMenu({ withShareTicket: true, menus: ['shareAppMessage', 'shareTimeline'] });
wx.onShareAppMessage(() => ({
  title: '一箭清空 · 你能几星通关？',
  imageUrl: 'share.png',   // 5:4，建议 500×400
}));
```

分享图可以用 `store/feature-graphic-1024x500.png` 裁成 500×400。

### 3.2 激励视频（金币）

`GameRoot.showShop()` 里的「看广告 +50」目前是演示逻辑，替换为：

```ts
const ad = wx.createRewardedVideoAd({ adUnitId: 'adunit-xxxxxxxx' });
ad.onClose((res) => {
  if (res && res.isEnded) grantCoins(50);
});
ad.show().catch(() => ad.load().then(() => ad.show()));
```

注意：

- 广告单元要在 **小游戏后台 → 流量主** 开通后创建；
- 首次 `show()` 失败要 `load()` 重试；
- 广告看完必须发奖，未看完不发；
- 不要用「强制看广告才能继续」的设计，审核容易不过。

### 3.3 震动 / 系统信息

`Platform.vibrate()` 已接 `wx.vibrateShort`。iOS 微信的震动支持有限，失败静默即可。

## 4. 审核与合规

| 项 | 做法 |
| --- | --- |
| 用户隐私保护指引 | 公众平台填写：收集哪些信息（本项目不收集）、用途、保存期限 |
| 未成年人保护 | 若含内购/抽奖，需接入实名与防沉迷；纯单机可先不做但要在说明里写清 |
| 类目 | 游戏 → 休闲益智 |
| 内容安全 | 无 UGC、无社交，风险低 |
| 诱导分享 | 不要用「分享才能继续」 |
| 虚拟支付 | iOS 端小游戏禁止虚拟支付（微信规则），金币只能靠广告/签到获取 |

提审时在「版本描述」里写清楚玩法与无内购，能减少来回。

## 5. 性能与体验清单

- [ ] 首屏 3 秒内进入首页（字体/背景预加载）
- [ ] 中低端安卓机稳定 50fps+（棋盘只有 20 条箭，Graphics 每帧不重绘，压力很小）
- [ ] 点击热区 ≥ 44pt（棋盘格 30pt+，按整格命中）
- [ ] 切后台再回来，计时器不跳变（`update` 的 dt 已 clamp）
- [ ] 分享卡片有图有文案
- [ ] 激励视频异常时不卡死（超时兜底）
- [ ] 包体 < 4MB
