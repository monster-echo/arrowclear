本项目**没有使用任何第三方版权素材**：Logo、吉祥物、图标、背景、音效全部由脚本生成，
可以随工程自由分发。字体使用开源的 ZCOOL KuaiLe（SIL OFL 1.1）。

## 2. 生成管线

```bash
# 1) 背景 + 应用图标 + 音效（Python / Pillow / ffmpeg）
python3 tools/gen_assets.py

# 2) 把 SVG 图标、Logo、吉祥物栅格化成 PNG（需要 Web 预览服务在 4173 端口）
npm run web &                 # 另开一个终端更稳
node tools/render-assets.mjs

# 3) 按实际用字重新子集化字体
python3 tools/subset_font.py
```

或者一条命令：

```bash
npm run assets
```

### 2.1 SVG 源

- 图标：`web/src/icons.ts`（内联 SVG，24×24 viewBox）
- Logo / 吉祥物：`web/src/art.ts`
- 六边形/箭头暗纹：`web/public/bg-arrows.svg`（Web 用），
  Cocos 用的背景由 `gen_assets.py` 用 Pillow 重绘（同一套视觉）

改完 SVG 后执行 `render-assets.mjs`，会按 `web/asset-lab.html` 里的排版逐元素截图，
自动写入 `assets/resources/art/`。

> `render-assets.mjs` 依赖 `http://localhost:4173/asset-lab.html`。
> 如果没有起服务，先 `npm run web`。

### 2.2 字体子集

```bash
# 首次需要装 fonttools（脚本假设在 /tmp/fontenv）
python3 -m venv /tmp/fontenv
/tmp/fontenv/bin/pip install fonttools brotli
python3 tools/subset_font.py
```

脚本会扫描 `web/src/*.ts`、`web/index.html`、`assets/scripts/**/*.ts` 里的所有字符，
把 1.4MB 的完整字体裁到 ~43KB。

**新增中文文案后必须重新跑一次**，否则 Cocos 里的新字会缺字形
（Web 端有系统字体兜底，Cocos 没有）。

完整字体保留在 `assets/art/fonts/ZCOOLKuaiLe-full.ttf`，不参与打包。

### 2.3 音效设计

`gen_assets.py` 用正弦/三角/方波 + 噪声 + 包络合成：

| 文件 | 听感 | 触发 |
| --- | --- | --- |
| `pop.mp3` | 上扬「啾」，固定音高 | 箭飞出 |
| `thud.mp3` | 低沉撞击 | 撞墙 |
| `click.mp3` | 轻点 | 按钮 |
| `coin.mp3` | 两连高音 | 广告发奖（+1 体力 / +1 提示） |
| `win.mp3` | 四音上行琶音 | 过关 |
| `lose.mp3` | 下行三音 | 失败 |

想换成真实音效：保持文件名与目录不变，直接替换 mp3 即可（建议 44.1kHz 单声道、
响度 -16 LUFS 左右、时长 < 1.5s）。Cocos 侧按 `audio/<name>` 加载。

| 角色 | 色值 |

箭头 9 色循环：
`#F2685F` `#FF9F43` `#FFC93C` `#6ACB5B` `#2FBF9E` `#4AA8F0` `#7C6BF2` `#C46BE8` `#F26BA0`

### 3.2 排版

- 展示字体：ZCOOL KuaiLe（圆润、卡通），用于标题、按钮、数字
- 正文字体：系统字体（iOS PingFang / Android Noto / 微信默认）
- 尺寸（720 宽设计稿）：标题 54、按钮 40、正文 30、小字 22

### 3.3 形状

- 卡片圆角 24–40，按钮圆角 26–34，按钮底部有 7–9px 的「厚度」阴影
- 棋盘格子圆角 0.62 格宽，白色 42% 透明度
- 箭头线宽 0.41 格宽，圆头圆角，带一条 20% 白的高光；箭头是带圆角的实心三角，且生成器强制头前 2 格直行，不会出现「到头拐弯」

## 4. 商店素材

| 平台 | 规格 | 文件 |
| --- | --- | --- |
| App Store 6.9" | 1320×2868 | `store/appstore/00-home-6.9.png` |
| App Store 6.7" | 1290×2796 | `store/appstore/01-home.png` 等 |
| Google Play 截图 | 1080×1920 | `store/googleplay/01-home.png`、`02-game.png` |
| Google Play 特色图 | 1024×500 | `store/feature-graphic-1024x500.png` |
| 应用图标 | 1024×1024（无透明） | `assets/art/app-icon-1024.png` |

重新截图的命令（`tools/cdp.mjs` 支持 `CW/CH/DPR` 环境变量）：

```bash
CW=430 CH=932 DPR=3 node tools/cdp.mjs shot http://localhost:4173/ store/appstore/01-home.png 900
CW=430 CH=932 DPR=3 node tools/cdp.mjs game http://localhost:4173/ store/appstore/02-game.png
CW=430 CH=932 DPR=3 node tools/cdp.mjs auto http://localhost:4173/ store/appstore/03-win.png
CW=540 CH=960 DPR=2 node tools/cdp.mjs shot http://localhost:4173/ store/googleplay/01-home.png 900
```

> `auto` 会自动通关第 1 关并截取结算弹窗；`game` 会点开始游戏并截棋盘。
