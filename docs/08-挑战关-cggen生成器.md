# 挑战关(第 501 关 · 千层箭阵，主线外彩蛋)与 cggen 构图生成器

## 范式

与 levelgen/peelgen 的根本区别:**放置时不要求航道干净,箭身可以落在任何已有箭的航道上(纠缠),只要求每放一支箭后依赖图仍是 DAG**(无环 ⟺ 必有解,拓扑序即一个解)。这就是《一箭又一箭》"处处纠缠"的来源。

## 三层结构(`assets/scripts/core/cggen.ts`)

1. **构图单元(motif)装配**——"包含/纠缠"是设计出来的:
   - 口袋套娃:中心箭外层层包壳(placePocket)
   - 总闸 fan-in:一支闸箭锁住多支箭,飞走瞬间连锁释放(placeFanIn)
   - 远距深链:A1 等 A2、A2 等 A3……门在航道远处(placeChain)
   - 多重门:一支箭的航道上横多支独立门(placeGates)
2. **背景增量填充**:4~9 格长箭随机撒,方向四向配额均衡,**连续直行 2 格后强拐弯**(蛇形 L/S 轮廓),每放一条验一次环(Kahn 拓扑)。
3. **收尾**:尾延长吸收空格(单箭 ≤12 格封顶),保留呼吸留白让"谁挡谁"可读。

## V3 设计要点(两轮试玩反馈迭代而来)

- 解密感 = **可读的依赖链**,不是满盘密度(满盘碎箭变成视觉找茬);
- 箭要蛇形不要直尺(turnRatio 硬门槛);
- 9×14 盘让格子渲染更大(与参照游戏同列数);
- 门箭 L 形钩,方向四向配额。

## 难度量化口径(`puzzleMetrics`)

depth(依赖链深)、freeAtStart / avgFree(可飞箭曲线)、waterfall(最大连锁释放)、turnRatio(蛇形占比)、dirSkew(方向集中度)、fill(填充率)。

要调难度:改 `challenge.ts` 的 SPEC → 重跑 `tools/pick-challenge.ts` 选新 seed → 固化回 `challenge.ts`。`tools/dump-challenge.ts <seed>` 输出 ASCII 盘面供目检。
